# Samera — Design. Make. Connect.

Sito in italiano realizzato con HTML, CSS e JavaScript, senza dipendenze di compilazione.

## Avvio locale

Dalla cartella `dist`: `python3 -m http.server 4173`.

## Contenuti e interazioni

Navigazione responsive, filtri degli ambiti applicativi, approfondimenti accessibili in dialog, creazione e download di un brief di progetto. I moduli non inviano dati e non usano archiviazione persistente. Collegare un recapito o un servizio di contatto quando disponibile. Gli ambiti illustrati sono possibilità da valutare, non prodotti già a catalogo.

## Direzione grafica

Rielaborazione del template Industry presente nella cartella originale `template`: fotografia industriale ampia, struttura per competenze, grigio antracite, accenti carta da zucchero e griglie pulite. Logo vettoriale ripreso dal riferimento fornito dal committente. Template originale conservato. Nessuna dipendenza dai suoi script o contenuti dimostrativi.

Le immagini editoriali sono generate con ImageGen e non documentano impianti o prodotti reali di Samera. Prompt in `ASSETS.md`.
